# Tic-Tac-Toe Game

A simple, interactive Tic-Tac-Toe game built with HTML, CSS, and JavaScript.

## Features

- Classic Tic-Tac-Toe gameplay
- Two players (X and O)
- Win detection
- Reset game functionality
- New game option
- Clean and responsive design

## How to Play

1. Open `index.html` in your web browser
2. Players take turns clicking on the grid to place their X or O
3. The game will automatically detect when a player wins
4. Use the "Reset Game" button to clear the board or "New Game" to start over

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Setup

No special setup required! Simply clone the repository and open `index.html` in your web browser to start playing.
